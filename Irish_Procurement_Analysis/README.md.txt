# Irish Public Procurement | Spending & Tender Analysis

## Project Overview

This project explores Irish public procurement data from 2013 to 2026 using an interactive Power BI dashboard. It focuses on tender activity, estimated procurement values, awarded contract values, procurement procedures, and spending categories.

## Tools Used

- Microsoft Power BI Desktop
- Power Query for data cleaning and transformation
- DAX for KPI measures
- CSV dataset

## Dashboard Features

- **Total Records:** Approximately 90,000 procurement records
- **Unique Tender Count:** Approximately 86,000 tenders
- **Total Estimated Value:** €304.07 billion
- **Total Awarded Value:** €217.13 billion
- **Interactive Filters:** Year and Contract Type
- **Visualisations:** Procurement procedures, top 10 spending categories, and annual estimated procurement values

## Key Observations

- Open procedures account for the largest number of procurement records.
- Minor Building Works and Civils is the leading category by estimated procurement value.
- Reported estimated procurement values rise substantially in the later years of the dataset.
- Large infrastructure projects and framework agreements contribute to the reported totals.

## Data Considerations

Estimated procurement values are not necessarily actual expenditure. Framework agreements may represent maximum potential contract values, and estimated and awarded totals are not necessarily directly comparable.

The dashboard presents reported values from the dataset rather than independently verified government spending totals.
